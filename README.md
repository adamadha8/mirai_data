# MIRAI synthetic reference package

This is a partial comparison reference, not original study data. Read PROVENANCE.md, COMPLETION_CHECKLIST.md, and 09_Validation_and_Comparison/reproducibility_gaps.md first. Python 3.11+ standard library is required. The manuscript is the only source of MIRAI-specific reported results; official public benchmark references are identified separately.

Folders 01–09 contain manuscript audit, synthetic benchmark, reference implementation, outcomes, statistics, audit, public benchmark integration, failure/overhead notes and validation. Run `python 04_Item_Level_Results/calculate_metrics.py`, `python 05_Statistical_Analysis/analyze.py`, `python 06_Evaluator_Audit/calculate_audit_metrics.py`, `python 03_Configurations_and_Implementation/reference_pipeline.py`, `python 09_Validation_and_Comparison/validate_all.py` and `python 09_Validation_and_Comparison/validate_semantics.py` from this folder. The generators overwrite current files; see reproducibility gaps before rerunning them. Reconstructed outcomes match reported counts by design, not because original experiments were replicated. Compare your own records by attributes and evidence relationships; synthetic identifiers have no correspondence to original IDs. Original records, prompts and responses are still required to independently reproduce the study.
