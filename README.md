# MIRAI synthetic reference package

This is a partial comparison reference, not original study data. Read PROVENANCE.md, COMPLETION_CHECKLIST.md, and 09_Validation_and_Comparison/reproducibility_gaps.md. Python 3.11+ and its standard library are required. The manuscript supplies MIRAI-specific reported results; official public benchmark references are identified separately.

Folders 01–09 contain the manuscript audit, synthetic benchmark, local configurations, item outcomes, statistical analysis, reconstructed audit, public benchmark notes, failure and overhead examples, and validation. Run `python 04_Item_Level_Results/calculate_metrics.py`, `python 05_Statistical_Analysis/analyze.py`, `python 05_Statistical_Analysis/targeted_bootstrap.py`, `python 06_Evaluator_Audit/calculate_audit_metrics.py`, `python 03_Configurations_and_Implementation/run_shared_cases.py`, `python 09_Validation_and_Comparison/validate_all.py`, `python 09_Validation_and_Comparison/validate_semantics.py`, and `python 09_Validation_and_Comparison/validate_style.py`. Rebuild selected outputs without overwriting this folder using `python rebuild.py --output <new-absolute-directory>`. This copies the dataset snapshot, not original records. Do not run older generator scripts over this folder; they overwrite files. Synthetic identifiers have no correspondence to original study IDs.
