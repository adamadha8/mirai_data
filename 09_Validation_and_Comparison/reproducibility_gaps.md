# Remaining gaps and limits

The scenarios are synthetic, generated from reusable templates and contain substantial repetition: see semantic_validation.md. Third-party records and updates link to dialogue, but the dialogue does not yet provide diverse, natural multi-turn histories, genuine uncertainty or a rich set of consent/authority scenarios. Many outcomes are allocated to match aggregate counts; wrong item answers are generic, and style verdicts are independent of actual response text. The latter means style checks are not semantically validated. The audit uses invented stratification and synthetic evaluator labels, not actual model decisions. Claim checker statistics differ from the manuscript and cannot be treated as verification. The eight configurations are simplified executable teaching models, not faithful baseline reproductions or the original API system. Some shared cases do not yet demonstrate an observable outcome difference for each configuration.

Tables 3 and 5 are covered by manuscript_vs_reference_results.csv; Table 6 is covered by table_6_comparison.csv. The package does not yet provide a complete numerical map of every confidence interval, contrast, abstract statement, Table 7 and Table 9 entry, or compute cluster-bootstrap intervals for all targeted metrics. No public dataset or model outputs were downloaded; official repositories and format documentation were verified but no official benchmark scoring was run. Dataset licensing should be reviewed before redistribution. Table 9 contains reported aggregates but no original observations; no timing run was represented as original evidence. The reconstructed source and temporal link checks do not validate all source consent cases or the semantics of every constructed text.

`generate_reference.py` creates the first-version base and overwrites generated data. To reproduce the revised package run, in order, `python generate_reference.py`, `python improve_reference.py`, `python repair_audit.py`, `python adjust_audit.py`, `python complete_package.py`, `python 05_Statistical_Analysis/analyze.py`, `python compare_table6.py`, and the two validation scripts. `complete_package.py` overwrites this document and the audit README, so retain revisions or restore them after rerunning; this regeneration workflow is unfinished. The original manuscript's individual records, exact prompts, judge outputs, public benchmark predictions and latency traces remain necessary for actual reproduction.
