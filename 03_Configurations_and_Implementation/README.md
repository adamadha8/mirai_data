# Eight local configurations

Run `python 03_Configurations_and_Implementation/reference_pipeline.py`. This deterministic toy uses supplied component scores, a fixed top-eight budget, exact-value claim extraction and a single deterministic rewrite. It does not use text-embedding-3-small, semantic inference, natural-language generation, genuine model prompts, trained models or API calls. It is a reference design, not the study implementation. Source and consent gate, valid-time selection, claim checking and recipient policy are separate switches. The three study-specific baselines have illustrative untyped, profile-priority and consolidation rules; the article does not specify their full algorithms. Latest-write-wins is approximated by the record date. The same records and top-k are used across modes. Each output records the retrieved IDs, draft, extracted claim, check, rewrite, final value and style. A fixed set of scores is not a substitute for actual retrieval embeddings.
