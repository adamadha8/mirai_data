# Official public benchmark integration

Verified 2026-11-23 against official repositories, not necessarily the releases used by the manuscript:

- LoCoMo: https://github.com/snap-research/locomo/tree/3eb6f2c585f5e1699204e3c3bdf7adc5c28cb376 ; data `data/locomo10.json`. Ten conversations; nested `conversation` session/date entries and `qa` objects with `question`, `answer`, `category`, and `evidence`. Official scoring entry point: `task_eval/evaluation.py` and `task_eval/evaluate_qa.py` in that commit. Repository README: https://github.com/snap-research/locomo/blob/3eb6f2c585f5e1699204e3c3bdf7adc5c28cb376/README.MD .
- LongMemEval: https://github.com/xiaowu0162/LongMemEval/tree/9e0b455f4ef0e2ab8f2e582289761153549043fc . Official documentation points to the cleaned LongMemEval-S at https://huggingface.co/datasets/xiaowu0162/longmemeval-cleaned/resolve/main/longmemeval_s_cleaned.json . The repository added cleaned histories in 2025; it is not established which release the article used. The file uses question_id, question_type, question, answer, question_date, haystack_session_ids, haystack_dates and haystack_sessions. Predictions are JSONL with question_id and hypothesis. Official evaluation is `src/evaluation/evaluate_qa.py`; the supplied judge prompts differ by task and call a model. See https://github.com/xiaowu0162/LongMemEval/blob/9e0b455f4ef0e2ab8f2e582289761153549043fc/src/evaluation/evaluate_qa.py .

Run `python 07_Public_Benchmarks/integrate.py inspect-locomo path/to/locomo10.json` or `python 07_Public_Benchmarks/integrate.py inspect-longmem path/to/longmemeval_s_cleaned.json`. These are structural ingestion checks, not official scoring and not experimental runs. The manuscript reports normalized partial-match LoCoMo F1 and LongMemEval binary correctness; the latter's evaluator and precise benchmark release are not specified. Run the official scoring scripts using the official repository requirements and a configured judge, and record code revision, dataset hash, generated predictions and judge version. The cleaned Hugging Face URL is not pinned; compute and save the downloaded file's hash and revision before using it. This package includes no benchmark data or actual benchmark predictions.
